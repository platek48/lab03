# Beeping.java
```java
package lab02;

public class Beeping implements Counter{
	Counter arg;
	public Beeping(Counter arg) {
		this.arg = arg;
	}
	@Override
	public void increase() {
		arg.increase();
		java.awt.Toolkit.getDefaultToolkit().beep();
	}

	@Override
	public int currentValue() {
		return arg.currentValue();
	}

	@Override
	public void reset() {
		arg.reset();
	}

}
```
Więcej pracy wymaga metoda dziedziczenia z zadań 4 i 5 przez ilość kodu do napisania. Przy metodzie użytej w Beeping nie ma potrzeby modyfikowania kodu w tak duży sposób. Gdyby w interfejsie Counter dopisano nową metodę, należało by też napisać jej odpowiednik w klasie Beeping, a w klasach z zadań 4 i 5 nie ma takiej potrzeby.
